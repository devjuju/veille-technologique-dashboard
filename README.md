# 📡 Tableau de bord de veille technologique

## 📌 Présentation

Ce repository contient le premier livrable du projet de veille technologique.

L'objectif est de mettre en place un système permettant de suivre régulièrement
les évolutions technologiques pertinentes pour l'activité de développeur.

La veille porte principalement sur :

- 🐘 PHP ;
- 🧩 Symfony ;
- 🔐 Cybersécurité ;
- 🏗️ Développement logiciel ;
- 🤖 Intelligence artificielle appliquée au développement ;
- 🐳 DevOps.

---

## 🎯 Objectifs

Cette veille technologique permet de :

- maintenir ses connaissances techniques à jour ;
- suivre les évolutions de PHP et Symfony ;
- identifier les nouvelles versions et les dépréciations ;
- surveiller les vulnérabilités de sécurité ;
- suivre les évolutions de l'intelligence artificielle appliquée au développement ;
- découvrir de nouvelles pratiques et technologies ;
- identifier des technologies pouvant faire l'objet d'une expérimentation.

---

## 🔭 Tableau de bord

Le tableau de bord principal de la veille est organisé avec Feedly.

Les sources sont regroupées dans trois catégories :


## 🔎 Méthode de veille

La veille repose sur plusieurs étapes :

```text
🔭 COLLECTE
       │
       ▼
📡 Feedly
       │
       ▼
🔎 TRI
       │
       ▼
🧠 ANALYSE
       │
       ▼
📌 CONSERVATION
       │
       ▼
🧪 EXPÉRIMENTATION
```

Les informations sont collectées à partir de sources sélectionnées, puis
triées selon leur pertinence.

Les actualités importantes sont ensuite analysées et documentées.

Lorsqu'une évolution semble particulièrement intéressante, elle peut faire
l'objet d'une expérimentation technique.
